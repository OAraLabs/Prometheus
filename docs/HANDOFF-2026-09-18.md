## READ THIS FIRST — five operational traps

These cost real time today. None is obvious from the code.

1. **The local Prometheus checkout is STALE.** `HEAD` is `ff9fae1`; `origin/main` is `a9a7b60`
   — **5 commits behind**. A survey agent read it, quoted real line numbers, and concluded a
   status vocabulary that had already changed. It nearly shipped a bug into a third client.
   Read contracts with `git show origin/main:<path>`, or pull first — but note the checkout is
   shared with other sessions, which is why I did not pull it.

2. **Prometheus commits must go through a worktree.** A pre-commit hook refuses commits in the
   shared dev checkout:
   `git -C $(git rev-parse --show-toplevel) worktree add .claude/worktrees/<name> -b <branch> origin/main`
   I lost uncommitted work once by checking out `main` over it in the shared tree.

3. **Branches can no longer be deleted, by design** (#476, new today). `no-branch-deletion`
   rulesets on Prometheus + beacon-desktop, `~ALL`, zero bypass actors. A delete returns
   `422 Repository rule violations found`. Two `test/4a-deletion-control` branches exist on
   purpose as standing proof — they cannot be removed without disabling the control.

4. **"Green" repeatedly meant "measured nothing"** — five separate times today:
   - `verify.sh` uses `xcodebuild -quiet`, which hides per-test output. A new test file that is
     not in the generated `.xcodeproj` reports `Executed 0 tests` and exits 0. **Check counts.**
   - beacon-desktop smokes run `out/main/*.js` — a **built artifact**. Editing `src/` and running
     a smoke directly tests the *previous* build. My first mutation test passed against
     deliberately broken code because of this.
   - Three assertions in the repos could not fail (e.g. "the terminal pane unmounted" passes when
     it never mounted). Two were pre-existing; one I wrote myself.

5. **Do not drive the iOS simulator's accessibility bridge.** `inspect` / the automation panel
   crashed SpringBoard twice (`XCTAutomationSession`, identical signature). Use `simctl` only —
   `install`, `launch`, `io … screenshot`. The app itself never crashed.
